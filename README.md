# Customer Churn Analysis

## Project Overview
An end-to-end data analytics project analysing customer churn in the telecommunications industry. The project uses Excel, SQL, Python and Power BI to identify customer churn patterns and provide actionable business recommendations.

## Objectives
- Analyse customer churn and retention rates.
- Identify customer segments with higher churn.
- Examine the relationship between contract types and churn.
- Understand churn patterns across internet services and payment methods.
- Present findings through interactive dashboards.

## Tools & Technologies
- Excel – Data cleaning and exploratory analysis
- MySQL – SQL queries and business analysis
- Python – Pandas, NumPy, Matplotlib and Seaborn
- Power BI – Interactive dashboard and visualisation

## Dataset
IBM Telco Customer Churn dataset.

- Total customers: 7,043
- Total columns: 21
- Target variable: Churn

## Key Performance Indicators

| Metric | Value |
|---|---:|
| Total Customers | 7,043 |
| Churned Customers | 1,869 |
| Retained Customers | 5,174 |
| Churn Rate | 26.54% |
| Retention Rate | 73.46% |

## Key Findings
- Overall customer churn rate is 26.54%.
- Month-to-month contracts have a churn rate of 42.71%.
- One-year contracts have a churn rate of 11.27%.
- Two-year contracts have a churn rate of 2.83%.
- Fiber optic customers have a churn rate of 41.89%.

## Business Recommendations
- Encourage customers to consider longer-term contracts.
- Investigate factors contributing to higher churn among fiber optic customers.
- Develop customer loyalty and retention programmes.
- Review customer experience across payment methods.

## Project Structure
- Dataset – Cleaned customer dataset
- Excel – Data analysis and dashboard
- SQL – Business analysis queries
- Python – Exploratory data analysis and visualisations
- PowerBI – Interactive dashboard
- Images – Dashboard screenshots

## Conclusion
The analysis highlights significant differences in churn across customer segments. These findings can help businesses identify customers who may require additional retention efforts.
